# Lunar Mission Control: Future Expansion Opportunities

## 1. Visual Perception & Mapping (The "Eyes")
Currently, the dashboard is blind. We can add visual context to make remote operation safer.

*   **Live Camera Feed:**
    *   **Feature:** Stream the `/camera/rgb/image_raw` from the RealSense D435.
    *   **Tech:** Use `cv2.imencode` in the bridge to send JPEG buffers to Streamlit (displayed via `st.image`).
    *   **Value:** Essential for teleoperation when the robot is out of line-of-sight.
*   **Occupancy Grid Map:**
    *   **Feature:** Render the `/map` topic (from `global_mapper`) as a heatmap.
    *   **Tech:** Use `matplotlib` or `plotly` to render the grid array. Overlay the robot's current pose arrow.
    *   **Value:** Verifies that the robot "knows" where obstacles are.
*   **Point Cloud Density:**
    *   **Feature:** A simple metric showing the number of valid points in the obstacle cloud.
    *   **Value:** Detects if the camera is obstructed (dust/mud) or if the lighting is too poor for the D435.

## 2. Advanced Telemetry & Analytics (The "Pulse")
Move beyond instantaneous numbers to trends and history.

*   **Time-Series Plotting:**
    *   **Feature:** Scrolling line charts for Battery Voltage, Velocity, and CPU Temp.
    *   **Tech:** `st.line_chart` hooked into a deque buffer in `state.py`.
    *   **Value:** Helps diagnose overheating or battery sag under load (e.g., digging into hard rock).
*   **Wheel Odometry vs. Visual Odometry:**
    *   **Feature:** Plot the divergence between `/odom` (localization) and wheel encoder-derived velocity.
    *   **Value:** Detects wheel slippage (stuck in sand) immediately.
*   **IR Radar Plot:**
    *   **Feature:** A semi-circle polar plot visualizing the IR sensor distances.
    *   **Value:** Intuitive "backup sensor" visualization for tight spaces.

## 3. Mission Autonomy & Control (The "Brain")
Shift from "Puppeteering" to "Commanding".

*   **Autonomy Macros:**
    *   **Feature:** Buttons for high-level sequences: "Initiate Dig", "Return to Home", "Dump Payload".
    *   **Tech:** Buttons that publish to a new `/cmd/sequence` topic or trigger an Action Client.
    *   **Value:** Reduces operator fatigue; ensures consistent mining maneuvers.
*   **Waypoint Navigation:**
    *   **Feature:** Input X/Y coordinates and hit "Go To".
    *   **Tech:** Publishes `PoseStamped` to `/goal_pose` (Nav2).
    *   **Value:** Basic semi-autonomous testing without writing code.
*   **PID Tuning Panel:**
    *   **Feature:** Sliders to adjust motor controller PID gains on the fly.
    *   **Value:** Critical for tuning the mining mechanism for different soil densities without recompiling.

## 4. System Observability & DevOps (The "Engine")
Deep introspection into the Jetson and Linux environment.

*   **Resource Monitor:**
    *   **Feature:** Real-time gauges for CPU Load, RAM Usage, and Disk Space.
    *   **Tech:** Python `psutil` library.
    *   **Value:** Prevents OOM (Out of Memory) crashes during long mapping runs.
*   **Network Health:**
    *   **Feature:** Ping latency to the robot and WiFi signal strength (RSSI).
    *   **Value:** Warns the operator before they drive out of range.
*   **Service Restarts:**
    *   **Feature:** "Hard Reset" buttons for specific nodes (e.g., "Restart Mapper", "Reset Camera Driver").
    *   **Tech:** `subprocess.run(["systemctl", "restart", ...])`.
    *   **Value:** Recovers from driver crashes without SSH-ing into the robot.

## 5. Data Operations (The "Black Box")
Manage the data generated by the robot.

*   **Rosbag Manager:**
    *   **Feature:** Start/Stop recording buttons with a filename input.
    *   **Value:** Ensures you capture data when interesting things happen.
*   **Map Management:**
    *   **Feature:** "Save Map" button to serialize the current `global_mapper` state to disk.
    *   **Value:** Persists the day's exploration.
*   **Log Export:**
    *   **Feature:** "Download Logs" button to zip up `/var/log` and the Roslogs.
    *   **Value:** Makes bug reporting much easier.
